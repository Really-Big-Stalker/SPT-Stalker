# SPT-Stalker

A S.T.A.L.K.E.R.-inspired overhaul for **Single Player Tarkov 4.1.x** (server mod, C# / .NET 10).

## Roadmap

| Stage | Content | Status |
|---|---|---|
| 1 | **Zone trader** "Bunker": a Cordon bunker trader with 4 loyalty levels | ✅ done |
| 2 | **Zone contracts**: random daily/weekly faction hunts and artifact hand-ins with new condition combos | ✅ done |
| 3 | **Artifacts**: 12 items in 4 tiers that spawn in stashes; 3D models | ✅ items, models Unity-ready, ⏳ bundles (built in the EFT SDK) |
| 4 | Custom story quest line for the trader | planned |
| 5 | New AI enemies (Zone factions) | planned (contracts use existing bots until then) |
| 6 | **Anomalies**: new fields every raid, 6 types, detector, artifacts inside, **radiation + gas masks** | ✅ server + client plugin (first version, see [docs/ANOMALIES.md](docs/ANOMALIES.md)) |

## Stage 1: the Zone trader

Kuzma "Bunker" runs a trade bunker on the edge of the Zone. He buys Zone loot (barter items, food, drink,
meds, weapons, ammo, intel, gas masks), repairs gear, and sells a kit that grows with loyalty:

* **LL1 Rookie:** PM, sawn-off MP-43, buckshot, bandages, AI-2, tushonka, sausage, vodka, grenades, PACA, flashlight
* **LL2 Experienced:** AKS-74U, MP-133, 5.45 PS, IFAK, morphine, 6B2, SSh-68, GP-5; scav pack for vodka + cigarettes
* **LL3 Veteran:** AK-74N, AKM, BT/PS rounds, Salewa, Propital, 6B23-1, GP-7; SVDS for Geiger counters + gunpowder
* **LL4 Master:** VSS Vintorez, SP-5/SP-6, Grizzly, eTG; 6B13 and Ratnik helmet for gold chains / bitcoin

Weapons and armour are sold as the game's default presets (full attachments and plates).

## Stage 2: Zone contracts

The Bunker joins the game's **daily and weekly tasks** (by default he's twice as likely to be the task giver as any
single vanilla trader). His tasks are generated by this mod instead of the vanilla generator:

**Hunts:** eliminate a Zone faction. Until the custom AI stage, factions map to existing enemies:

| Faction | Enemies | Where | From level |
|---|---|---|---|
| Bandits | Scavs | any / one map | 1 |
| Mercenaries | PMCs | any / one map | 5 |
| Military | Raiders | Reserve, Labs | 15 |
| Renegades | Rogues | Lighthouse | 20 |
| Monolith | Cultists | Customs, Woods, Shoreline, Factory | 20 |

Each hunt can roll extra conditions (1 for dailies, up to 2 for weeklies): **at night**, **wearing a gas mask**,
**survive and extract**, **within 25 m** / **beyond 75 m**, **headshots only**, **shotguns only**, **pistols only**,
**5.45×39 only**. Harder rolls pay more.

**Artifact hunts:** hand over found-in-raid artifacts. Higher levels unlock rarer artifacts
(tier 2 from level 10, tier 3 from 22, tier 4 from 35). Weeklies ask for more, and for mixed types.

Rewards come from the game's own reward system (money, items, Bunker reputation) scaled by difficulty.
Everything is tunable in `data/contracts/contracts.json`: factions, kill counts, modifier chances, texts.

## Stage 3: Artifacts

| Tier | Artifacts |
|---|---|
| 1 (common) | Jellyfish, Stone Blood, Sparkler, Slime |
| 2 (uncommon) | Moonlight, Flash, Thorn, Fireball |
| 3 (rare) | Night Star, Battery, Soul |
| 4 (legendary) | Compass |

Artifacts spawn in **buried barrel caches, ground caches, dead scavs, duffle bags, toolboxes and weapon boxes** on every
map, weighted by rarity. The Bunker buys them, and they can be sold on the flea market. Edit `data/artifacts/artifacts.json`
to change prices, spawn chances, containers, maps or text.

They currently use placeholder models from vanilla items. Their own models are already prepared for the EFT SDK in
`art/artifacts/unity/<key>/` (FBX + baked textures, preview: `art/artifacts/previews/_sheet_baked.png`). The remaining
Unity step, and how to bring in your own models, is in [docs/ARTIFACT_MODELS.md](docs/ARTIFACT_MODELS.md).

## Install

1. Download the `SPTStalker` artifact from the latest successful **Build** run under the repo's Actions tab (or build it yourself, below).
2. Copy the package's `SPT` folder over your SPT install. You get the server mod in `SPT/user/mods/SPTStalker/`
   and the client plugin (anomalies) in `SPT/BepInEx/plugins/SPTStalker/SPTStalker.Client.dll`.
3. Start the server. You should see:
   `[SPT-Stalker] 12 artifacts registered`, `[SPT-Stalker] Trader 'Bunker' is open for business (47 offers)` and
   `[SPT-Stalker] Zone contracts ready (5 factions, 9 modifiers)`.
4. Dailies/weeklies only regenerate when they reset, so the Bunker's contracts appear after your next task refresh.

## Build

Requires the .NET 10 SDK.

```bash
python3 tools/validate_data.py
dotnet build src/SPTStalker/SPTStalker.csproj -c Release
# output: src/SPTStalker/bin/Release/SPTStalker/  -> copy to SPT/user/mods/SPTStalker
```

The project references the SPT 4.1.2 NuGet packages, which are the newest published for 4.1. The mod declares
`~4.1.0`, so it loads on any 4.1.x server, including 4.1.6.

## Editing the trader

Everything lives in `src/SPTStalker/data/trader/`. Edit it there, or directly in the installed mod folder.

| File | What it controls |
|---|---|
| `settings.json` | Restock time, flea-market listing, name / nickname / location / description per language (`en`, `ru`, ...; the `defaultLocale` text is used for every other language) |
| `base.json` | Trader id, loyalty level requirements, what he buys, repairs |
| `assort.json` | What he sells |
| `avatar.jpg` | Trader portrait (placeholder art; swap in your own 256×256 jpg) |

An `assort.json` offer looks like this:

```json
{
  "key": "rookie_pm",              // unique and permanent; the offer's in-game id is derived from it
  "name": "PM pistol",             // just a label for you
  "tpl": "5448bd6b4bdc2dfc2f8b4569",
  "loyaltyLevel": 1,
  "stock": 6,                      // or "unlimited": true
  "buyLimit": 2,                   // per restock, optional
  "price": { "currency": "RUB", "amount": 11000 }
  // or: "barter": [ { "name": "Vodka", "tpl": "5d40407c86f774318526545a", "count": 1 } ]
}
```

Item ids can be found in SPT's `ItemTpl` list or the item database (`SPT_Data/database/templates/items.json`).
Bad entries are logged and skipped instead of stopping the server.

## Project layout

```
src/SPTStalker/
  ModMetadata.cs                 mod name/version, SPT version range
  Common/StableId.cs             ids that stay the same between server restarts
  Trader/StalkerTraderLoader.cs  registers the trader (avatar, restock, flea, locales, stock)
  Trader/TraderAssortBuilder.cs  assort.json -> server assort (presets, prices, barters)
  Trader/TraderSettings.cs       JSON models for settings.json / assort.json
  Artifacts/                     artifact items + stash spawns
  Contracts/                     contract generator + Harmony hooks into the repeatable task generators
  Common/                        stable ids, locale helper
  data/trader/                   trader data (see above)
  data/artifacts/artifacts.json  artifacts, rarity, spawn containers
  data/contracts/contracts.json  factions, modifiers, contract texts
art/artifacts/                   generated 3D models (.glb) and previews
tools/validate_data.py           data checks, also run in CI
tools/artifact_models/           procedural artifact model generator
tools/blender/                   prepare any model for the EFT SDK (scale, origin, bake textures, FBX)
tools/unity/Editor/              EFT SDK editor script: builds item prefabs + bundle labels
tools/link_bundles.py            built bundles -> bundles.json + artifact prefabPath
docs/ARTIFACT_MODELS.md          meshes -> Unity bundles -> in game
```
